# 🌱 Plant Disease Detection

## About
This project uses Deep Learning and a CNN model
to classify plant leaf images into disease categories.

## Technologies Used
- Python
- TensorFlow and Keras
- CNN (Convolutional Neural Network)
- Google Colab

## Dataset
PlantVillage dataset.

## Workflow
1. Dataset collection
2. Image preprocessing
3. CNN model training
4. Model evaluation
5. Disease prediction

## How to Run
Open Plant_Disease.ipynb in Google Colab
and run the cells in order.

## Disclaimer
Predictions are experimental and should not replace
professional plant disease diagnosis.
